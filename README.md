# Cross-Media Recommender System

This project is a content-based recommender system that suggests similar media (books, games, movies, and shows) based on user input. The recommendations are generated by analyzing the textual content of the media, such as the overview, genres, and title.

## Features

-   Recommends similar media across different types (books, games, movies, shows).
-   Uses a TF-IDF vectorizer to represent the textual content of the media.
-   Calculates the cosine similarity between media to find similar items.
-   Provides a simple and interactive user interface using Streamlit.

## Dataset

The recommender system uses four datasets:

-   `books.csv`: Contains information about books.
-   `games.csv`: Contains information about games.
-   `movies.csv`: Contains information about movies.
-   `shows.csv`: Contains information about TV shows.

These datasets are cleaned, merged, and preprocessed to create a master dataframe (`master_df.pkl`) that is used for training the recommender system.

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/your-repository.git
    ```
2.  Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage

1.  Run the Jupyter Notebook to generate the master dataframe and similarity matrix:
    ```bash
    jupyter notebook notebook.ipynb
    ```
    This will create the `master_df.pkl` file and the `similarity_chunks` directory.

2.  Run the Streamlit app:
    ```bash
    streamlit run app.py
    ```
    This will open the recommender system in your web browser.

## File Descriptions

-   `app.py`: The main file for the Streamlit web application.
-   `notebook.ipynb`: A Jupyter Notebook that performs data cleaning, preprocessing, and model training.
-   `data/`: A directory containing the four datasets.
-   `similarity_chunks/`: A directory containing the pre-computed similarity matrix chunks.
-   `master_df.pkl`: A pickle file containing the preprocessed master dataframe.
-   `requirements.txt`: A file listing the required Python packages and their versions.
-   `README.md`: This file.
